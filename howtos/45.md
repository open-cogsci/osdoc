# How to collect gaze data continuously in an eye-tracking experiment

Most eye trackers, such as the EyeLink, write gaze data automatically to a log file, in which case there is no need to write gaze data to a file yourself. However, if you do need to collect gaze data continuously in an eye-tracking experiment, you can do this as follows:

1. Initialize the eye tracker using the PYGAZE_INIT item.
2. Start recording eye movements using the PYGAZE_START_RECORDING item.
3. Create a loop that continuously retrieves the current gaze position using the `eyetracker.sample()` function.
4. Store the gaze data in a list or write it to a file within the loop.
5. Break the loop when a specific condition is met, such as a button press or a time limit.
6. Stop recording eye movements using the PYGAZE_STOP_RECORDING item.
7. Analyze the collected gaze data as needed.

Example:

```python
my_keyboard = Keyboard(timeout=0)
my_gaze_data = []
while True:
    # the eyetracker object is created by PYGAZE_INIT
    # eyetracker.sample() returns a tuple of x and y coordinates
    xy = eyetracker.sample()  
    my_gaze_data.append(xy)
    key, timestamp = my_keyboard.get_key()
    if key is not None:
        break
```


# How to trigger an event based on gaze position

To trigger an event, such as displaying a SKETCHPAD, based on gaze position:

1. Initialize the eye tracker using the PYGAZE_INIT item.
3. Start recording eye movements using the PYGAZE_START_RECORDING item.
2. Show a SKETCHPAD (or Canvas) in which the target area of interest (AOI) is defined as a named element.
5. Use an INLINE_SCRIPT to wait until gaze position falls within the target AOI or until a timeout expired.
    ```python
    TIMEOUT = 5000
    TARGET_AOI = 'my_target_aoi'  # needs to match the name of an element on a SKETCHPAD or Canvas
    t0 = clock.time()
    my_canvas = items['my_sketchpad'].canvas  # use the canvas from the SKETCHPAD item that contains the target AOI
    while True:
        x, y = eyetracker.sample()
        # Eye-tracking data uses 0, 0 for the top-left. OpenSesame use 0,0 for the display center. We need to correct for this.
        x += my_canvas.left
        y += my_canvas.top
        # Check if gaze falls within the target area of interest
        if (x, y) in my_canvas[TARGET_AOI]:
            print('gaze on target!')
            break
        # Also include a timeout to avoid the experiment from freezing indefinitely
        if clock.time() - t0 >= TIMEOUT:
            print('timeout occurred!')
            break
    ```
6. Show another SKETCHPAD, or implement some other event that should be triggered based on gaze position.
7. Stop recording eye movements using the PYGAZE_STOP_RECORDING item.
