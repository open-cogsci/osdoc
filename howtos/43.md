# How to create a math problem verification task with additions and subtractions

To create a math problem verification task with additions and subtractions in OpenSesame:

1. In the LOOP item, prepare a table with columns for the problem type (addition or subtraction), the operands, and the correct answer.
2. Create a SEQUENCE item to represent a single trial.
3. Inside the SEQUENCE, add a SKETCHPAD to display the math problem using the variables from the LOOP.
4. Add a KEYBOARD_RESPONSE item to collect the participant's response.

# How to group and randomize math problems by operation type

To group and randomize math problems by operation type (addition and subtraction) in OpenSesame:

1. Create a SEQUENCE item to represent a block of trials.
2. Inside the SEQUENCE, add one LOOP item for the addition problems (*addition_loop*) and another LOOP item for the subtraction problems (*subtraction_loop*).
3. After the *subtraction_loop*, add a linked copy of the *addition_loop* so that it occurs twice, once at the start, and once at the end of the SEQUENCE.
4. Use `subject_parity == "even"` as the run-if expression for the first *addition_loop*, and `subject_parity == "odd"` for the second *addition_loop*. This way, the order of the LOOPs will be counterbalanced between participants.
5. Add a SEQUENCE item inside each LOOP to represent a single trial.

# How to create trials of ascending difficulty

To create blocks of trials of ascending difficulty

1. Prepare a LOOP table (*block_loop*) that defines trials of various levels of difficulty, such as math problems of different difficulty.
2. In the LOOP table, add a column called `difficulty` that contains a numeric score for the difficulty of each trial.
3. Add the script of the LOOP, and just before the line that contains the `run` command use the `sortby` advanced LOOP operation to sort the table by difficulty:
    ```
    sortby difficulty
    ```
4. Add a SEQUENCE (*trial_sequence*) to the LOOP, and use this to implement your trials based on the variables defined in the LOOP.
