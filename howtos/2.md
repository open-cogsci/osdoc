# How to use a response in a run-if expression

To use a response collected in a KEYBOARD_RESPONSE item in a run-if expression to select which item is run:

1. In a SEQUENCE item, set the run-if expression of one child item to `response == 'left'` to execute it only if the left arrow was pressed.  
2. Set the run-if statement of another child item to `response == 'right'` to execute it only if the right arrow was pressed.
3. Run-if expressions should be valid Python expressions.

# How to use JavaScript code in an OSWeb experiment

To use JavaScript code in an experiment running in OSWeb:

1. Insert an INLINE_JAVASCRIPT item into your experiment
2. For code that needs to be executed during preparation (for example the preparation of a trial in the case of a trial SEQUENCE), use the 'Prepare' phase
3. For code that needs to be executed during executing, use the 'Run' phase
4. Avoid naming conflicts with variables defined in the other parts of the experiment
5. Global variables from INLINE_JAVASCRIPT items are also available in the user interface, for example in run-if expressions
6. Variables from the user interface, for example response variables, are available as global variables in INLINE_JAVASCRIPT items
