# How to run an experiment in a web browser using OSWeb

To run an experiment in a web browser using OSWeb, follow these steps:

1. Open the Experiment Properties and select 'In a browser with OSWeb (osweb)' in the 'Run experiment' section.
2. Click any of the 'Run' buttons to start the experiment.
3. If the experiment is not compatible with OSWeb, an error message will appear that details the compatibility issues. 
4. If there are no compatibility issues, the experiment will open in a new browser window. Note that even though the experiment is running in a web browser, it is still executing locally on your own computer.
5. When the experiment is finished, the data will be downloaded in `.json` format. This data file can then be converted to `.xlsx` or `.csv` format for further analysis.

# How to access the OSWeb control panel

For more control over OSWeb experiments, you can access the OSWeb and JATOS control panel:

1. Click on the Tools menu
2. Select 'OSWeb and JATOS control panel'
3. The OSWeb and JATOS control panel will appear, offering configuration options such as: 
   - Possible subject numbers when running in JATOS
   - Enabling fullscreen mode 
   - Showing the OSWeb welcome screen
   - Bypassing compatibility checks
   - Customizing welcome text
   - Specifying external JavaScript libraries to load

# How to host an experiment online using JATOS / MindProbe

To host an experiment online so that it can be run by participants, you need to publish it to JATOS:

1. In OpenSesame, open your experiment and check that it is compatible with OSWeb 
2. In the OSWeb and JATOS control panel, configure your JATOS server (such as https://jatos.mindprobe.eu) and your API token, which you can generate by logging into your JATOS server in a web browser.
3. In the OpenSesame menu, select 'Save and publish to JATOS' (or 'Save and publish to MindProbe' depending on which server you have configured).
4. Your experiment will now be uploaded to your JATOS server.
9. Once uploaded, you can generate links by logging into your JATOS server in a web browser to allow participants to run your experiment in a web browser

Alternatively, you can export the experiment to a JATOS archive (jzip) using the OSWeb and JATOS control panel, and import this archive through the JATOS server.
