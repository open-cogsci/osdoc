# How to set up response keys in OpenSesame

To set up response keys in OpenSesame:

1. Create a keyboard_response item in your experiment.
2. In the keyboard_response item properties, specify the allowed keys in the "Allowed responses" field (e.g., 'z;/').
3. Set the timeout duration in the "Timeout" field to limit the response window (e.g., '2500' for 2500ms).
4. Add the keyboard_response item to your trial sequence.
5. Run your experiment and test if the response keys are working as expected.

# How to debug response key issues in OpenSesame

To debug response key issues in OpenSesame:

1. Double-check that the response keys are correctly specified in the keyboard_response item properties.
2. Ensure that the keys are not mapped to any other functions or shortcuts in your operating system or other software.
3. Test your experiment with different response keys to isolate the issue.
4. Print the values of response variables (e.g., 'response', 'response_time') to the debug window, or monitor them in the Variable explorer, to monitor their values during the experiment.
5. Check the console for any error messages related to the keyboard_response item or response handling.

# How to use audio stimuli in OpenSesame

To use audio stimuli in OpenSesame:

1. Import your audio files into the file pool.
2. Create a sampler item in your experiment.
3. In the sampler item properties, select the audio file from the file pool.
4. Set the duration and other playback settings for the audio stimulus.
5. If you want participants to press a key in response to the sound, add a keyboard_response item after the sampler item in the trial sequence.

# How to troubleshoot timing issues in OpenSesame

To troubleshoot timing issues in OpenSesame:

1. Close any unnecessary background applications that may interfere with the timing of your experiment.
2. Use a high-precision backend, such as 'psycho', for better timing accuracy.
3. Record the actual timing of events and compare them with the expected timing. You can do this with the `clock.time()` function `inline_script` items or by relying on onset time variables that are automatically created by OpenSesame. For example, the onset time of a sketchpad called 'target' is stored as the variable 'time_target'.
