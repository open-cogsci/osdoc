# How to abort an OpenSesame experiment

There are two ways to abort an OpenSesame experiment while it is running. To gently abort the experiment:

1. Press the `Escape` key to pause the experiment. A confirmation prompt will appear.
2. Press the `q` key to confirm quitting the experiment. 
3. The experiment process will cleanly exit and you will return to the OpenSesame window.

To kill the experiment process, for example when it is unresponsive:

1. Switch to the OpenSesame window.
2. Click on the icon marked 'Forcibly kill the experiment' in the main toolbar.
3. The experiment process will now be killed.
