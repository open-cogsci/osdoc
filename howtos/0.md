# How to troubleshoot an experiment that fails to open correctly

When an experiment fails to open correctly in OpenSesame, you can take the following steps to troubleshoot the issue:

1. Check that you are using the most recent version of OpenSesame. If you are using an outdated version, the experiment may not be compatible.
2. If you are using a recent version of OpenSesame, close OpenSesame completely and then re-open the experiment.
3. Check the debug window (View → Show console) for error messages that may indicate why the experiment is failing to open.
5. If you still cannot get the experiment to open correctly, try downloading the experiment again. The downloaded file may have been corrupted.
6. If problems persist, contact the original author of the experiment for further assistance.

# How to find help when working with OpenSesame

If you need help with OpenSesame, there are several places you can look:

1. Consult the built-in help documentation by clicking the help buttons that appear throughout the interface, or by clicking Help in the main menu. This will open the documentation in your web browser.
2. Visit the documentation website at [osdoc.cogsci.nl](https://osdoc.cogsci.nl). This site contains an extensive manual as well as several step-by-step tutorials.
3. Watch video tutorials on the [YouTube channel](https://www.youtube.com/sebastiaanmathot). These videos cover many basic topics to help you get started with OpenSesame.
4. Ask a question on the [OpenSesame forum](https://forum.cogsci.nl). This forum is the main place for getting personalized help with OpenSesame. Be sure to include enough details, such as a description of what you are trying to achieve, and screenshots of things that you need help with.
5. Ask me! As an AI assistant with access to the OpenSesame documentation, I will be able to help you with many things.

# How to share an experiment with others

To share an experiment with others, so that they can run and/ or inspect the experiment themselves, you can take the following steps:

1. In OpenSesame, open the experiment that you would like to share.
2. Make sure that the experiment contains no sensitive information, such as participant data.
3. Save the experiment and close it.
4. Locate the experiment file (`.osexp`) on your computer.
5. Upload this file to a file sharing service, such as Google Drive, Dropbox, or the Open Science Framework (OSF).
6. Once the upload is complete, make sure that the file is shared with the intended recipients.
7. Send the download link to the people with whom you want to share the experiment.
8. The recipients can then download the experiment and open it in their own copy of OpenSesame.

# How to import (open) an experiment into OpenSesame

To import (open) an experiment into OpenSesame, for example an experiment that someone else has shared with you, take the following steps:

1. Download the experiment file, which should have the `.osexp` extension, to your computer.
2. Launch OpenSesame.
3. In the menu, click on File → Open and browse to the location where you have downloaded the `.osexp` file.
4. Select the `.osexp` file and click on 'Open'.
5. The downloaded experiment will now open in OpenSesame.
