# How to create a basic experiment structure in OpenSesame

To create a basic experiment structure in OpenSesame:

1. Create a new experiment and add a loop item to the main sequence, which is generally called 'experiment'.
2. Rename the new loop item to 'block_loop' to indicate that it corresponds to a block of trials.
3. Add a sequence item as the item to run for the block_loop.
4. Rename the new sequence to 'trial_sequence' to indicate that it corresponds to a single trial.
2. Within the trial sequence item, add sketchpad items for each visual stimulus display of your trial (e.g., baseline, fixation, emotion induction, instruction, emotion regulation, black screen, relax, and rating).
3. Adjust the duration of each sketchpad item according to your experimental design.
4. Add a keyboard_response item after the display that participants should respond to.

# How to present images randomly in OpenSesame

To present images randomly in OpenSesame:

1. Create a loop item and add a list of image file names as rows to a column of the loop table called 'image_file'
2. In the loop item's properties, set the "Order" to "random".
3. Create a sketchpad item within the loop and add an image element to it.
4. Add the script of the image element, and set the "file" keywowrd to "{image_file}": `file="{image_file}"'. The curly braces indicate that image_file is a Python expression that refers to the variable `image_file`.
5. Each iteration of the loop will now display a randomly selected image from your list.

# How to implement different instructions based on trial conditions

To implement different instructions based on trial conditions:

1. Decide whether you want to vary the instruction from trial to trial, in which case the instructions below relate to the block_loop and the trial_sequence (assuming that you named your items following the standard OpenSesame naming conventions); or from block to block, in which case the instructions below relate to the experimental_loop and block_sequence.
1. In your loop table, create a column called `instruction_text` that contains the text that should be presented as instruction to the participant (e.g., "maintain" or "decrease").
2. Add a sketchpad item for the instruction screen to the start of the sequence.
3. Add a text element to the instruction sketchpad to show the text "{instruction_text}".
4. The curly braces indicate that instruction_text is a Python expression that refers to the variable `instruction_text`.
5. OpenSesame will now display the appropriate instruction for each trial or each block based on the value in the loop table.

# How to create a rating scale in OpenSesame

OpenSesame does not contain a rating scale by default, but it is easy to implement one.

How to create a rating scale using a form_multiple_choice item:

1. Add a form_multiple_coice item to your experiment.
2. Make sure that 'Allow multiple options to be selected' is disabled.
3. Add each rating option as a separate line in the options field at the bottom of the controls.

How to create a rating scale using a sketchpad item:

1. Design the rating scale using one sketchpad element, called 'rating_sketchpad', for each clickable option. For example, you could use five filled circles or five images of a star to create five-point likert scale.
2. Give each clickable element a unique name, such as 'rating1', 'rating2', etc.
3. After rating_sketchpad, insert a mouse_response.
4. In the mouse_response, select rating_sketchpad as 'Linked sketchpad'.
5. The clicked option will now be available through the `cursor_roi` variable.
6. To let the experiment continue only when participants have clicked on an option (and not the background, for example), put the mouse_response in a loop that breaks only when an option was clicked, for example with a break-if expression: `'cursor_roi.startswith('rating')`.
