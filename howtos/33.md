# How to show or hid the mouse cursor in OSWeb

To make the mouse cursor visible or invisible in OSWeb:

1. Insert an inline_javascript at the location where you want to make the mouse cursor visible.
2. In the run phase of this inline_javascript item, use the following script to change the visibility of the mouse cursor
   ```javascript
   // To make the cursor visible
   runner._renderer.view.style.cursor = 'default'
   // To hide the cursor
   runner._renderer.view.style.cursor = 'none'
   ```
   
Important note: this script directly accesses the OSWeb internals, which may break in future versions of OSWeb.

# How to create a custom mouse-tracking task in OSWeb

To create a custom mouse-tracking task using JavaScript in OSWeb:

1. Create a new inline_javascript item in your experiment.
2. In the prepare phase of the inline_javascript item, set up the necessary variables and functions for your mouse-tracking task. For example:
   ```javascript
   var startTime;
   var mousePositions = [];
   
   function recordMousePosition(e) {
     var currentTime = new Date().getTime();
     var elapsedTime = currentTime - startTime;
     mousePositions.push({x: e.clientX, y: e.clientY, time: elapsedTime});
   }
   ```
3. In the run phase of the inline_javascript item, attach the `recordMousePosition` function to the `mousemove` event listener:
   ```javascript
   document.addEventListener('mousemove', recordMousePosition);
   startTime = new Date().getTime();
   ```
4. Present your stimuli and perform any necessary task-specific logic in the run phase.
5. When the task is complete, in the run phase of another inline_javascript item, remove the event listener and save the recorded mouse positions by assigning it as a string to a global variable (`mouse_positions`), which will be logged by the LOGGER item.
   ```javascript
   document.removeEventListener('mousemove', recordMousePosition);
   mouse_positions = JSON.stringify(mousePositions);
   ```
6. Save the changes to the experiment script.
7. Run the experiment to test the custom mouse-tracking task.

# How to display the mouse coordinates in real-time in OSWeb

To display the mouse coordinates in real-time using JavaScript in OSWeb:

1. Create a new inline_javascript item in your experiment.
2. In the prepare phase of the inline_javascript item, create a text element to display the mouse coordinates:
   ```javascript
   var coordinatesDisplay = document.createElement('div');
   coordinatesDisplay.style.position = 'absolute';
   coordinatesDisplay.style.top = '10px';
   coordinatesDisplay.style.left = '10px';
   coordinatesDisplay.style.fontSize = '16px';
   document.body.appendChild(coordinatesDisplay);
   ```
3. In the same script, attach a function to the `mousemove` event listener to update the coordinates display:
   ```javascript
   document.addEventListener('mousemove', function(e) {
     coordinatesDisplay.innerHTML = 'X: ' + e.clientX + ', Y: ' + e.clientY;
   });
   ```
4. Optionally, you can customize the appearance of the coordinates display by modifying the CSS styles in the prepare phase.
5. Save the changes to the experiment script.
6. The mouse coordinates are now shown continuously in the top left of the browser window.
