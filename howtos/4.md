# How to show a form with image and text input in OSWeb

To create a recall trial where an image is shown and the participant types in a response in OSWeb, you can use an INLINE_HTML item with the following code:


```html
<input type='text' name='text_response'>
<img id='my_image_element'>
<input type='submit' value='ok'>

<script>
// Assume that the variable `my_image` defines the name of the image in the file pool
document.getElementById('my_image_element').src = pool[my_image].data.src
</script>
```
