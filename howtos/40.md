# How to log complex data types in OpenSesame

By default, the LOGGER only logs simple data types (`int`, `float`, `str`, `bytes`, `None`). This is to avoid the log file from being polluted by complex data types, which are often not intended for logging. However, in some cases you may want to also log complex data types. You can do this by explicitly entering the name of the to-be-logged variable in the Include field of the LOGGER item. Always check that your variables are logged correctly!
