# How to create an experiment with different lists for different participants in OpenSesame

To create an experiment with multiple lists, varied per participant, in OpenSesame:

1. Prepare your lists as `.csv` or `.xlsx` spreadsheets and put them in the file pool.
2. Make sure the lists have regular names, such as `list-0.csv`, `list-1.csv`, etc.
3. Add a LOOP item (*block_loop*) to experiment.
4. In the LOOP, select File under Source.
5. In the File input that now appears, indicate an expression that selects the correct list. For example, if you have four lists (0, 1, 2, 3) that you want to counterbalance based on the subject number, then you could use the following expression:
    ```
    list-{subject_nr % 4}.csv
    ```
6. Add a SEQUENCE (*trial_sequence*) to the LOOP, and use this to implement your trial.
