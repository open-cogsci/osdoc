## Backwards compatibility

OpenSesame 4.1 is fully backwards compatible with 4.0.

  
## A familiar but more polished user experience

Several elements of the user interface have been rewritten from scratch, using components from Sigmund Analyst (see below). You may hardly notice the difference at first, because the appearance of the user interface has largely stayed the same. However, you will find that the interface is more responsive and smoother. Also, INLINE_SCRIPT items now provide better context-sensitive completions and tooltips.
  

## SigmundAI: an AI-copilot for OpenSesame

[SigmundAI](https://sigmundai.eu) is an AI-research assistant. It is powered by the latest AI-technology that is also used by ChatGPT+ and Claude. However, different from these general-purpose chatbots, SigmundAI has expert knowledge of OpenSesame and other scientific Python packages that other chatbots struggle with.

You can now use SigmundAI direcly from within the OpenSesame user interface to develop experiments together. See also:

- %link:manual/sigmund%
  

## Sigmund Analyst: a new code editor focused on data analysis

[Sigmund Analyst](https://github.com/open-cogsci/sigmund-analyst) is a code editor that is bundled with OpenSesame. It replaces Rapunzel, which was bundled with previous versions of OpenSesame. Sigmund Analyst has a sleek, minimal user interface that allows you to focus on data analysis.
